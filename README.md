# Виртуальный помощник для написания кода на 1С

## Описание
Данный помощник позволяет генерировать простые тексты на языке разработки 1С.
В качестве базовой модели использована локальная qwen2.5:14b.
Но можно доработать для использования с любой другой, например - gigachat.
В папках data/code_examples и data/docs можно разместить примеры кода и документации соответственно,
тогда модель будет использовать RAG для выдачи более точных результатов.
Для сохранения контекста использовал InMemorySaver - в оперативной памяти
Так же разработан небольшой фронт на js и бэк с использованием fastapi для удобной проверки помощника.
Естественно, это базовая толком необученная модель, только лишь показать умения написания агента.
Разработка велась в windows среде

## Инструкция
### Установка модели

#### Windows
скачать OllamaSetup.exe с ollama.com

### Запуск модели
ollama pull qwen2.5:14b
ollama serve  # поднимает REST API на localhost:11434

### Проверка того, что модель работает
curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen2.5:14b","messages":[{"role":"user","content":"Напиши запрос 1С для выборки номенклатуры с ценами"}]}'

### Развёртка и запуск
Выкачать проект с гита;
Перейти в папку с исходниками;
Запустить cmd;
Выполнить команду: python -m uvicorn start:app --reload;
Далее, по адресу: http://127.0.0.1:8000/ будет доступна вьюха для тестирования помощника
